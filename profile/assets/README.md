# Bonjou logo exports

These files are copied from `bonjou-app/bonjou-web/public/brand/`.
The canonical geometry is `bonjou-web/src/share/brandMark.json`; run
`npm run generate:brand` there before updating these copies.

Use `bonjou-avatar.png` for the GitHub organization picture. Its padding
keeps the mark clear in square and circular crops. Use `bonjou-mark.svg`
on transparent backgrounds in repository documentation.
